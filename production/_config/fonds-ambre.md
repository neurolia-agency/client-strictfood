# Fonds Ambre Incandescente — Catalogue de variantes

> Bibliothèque de fonds et concepts visuels utilisant la couleur **Ambre Incandescente** (`#FABA43`) comme élément dominant.
> Chaque variante a un ID unique appelable dans les briefs via le champ `Fond: [ID]`.
> Le prompt engineer injecte le bloc `prompt_block` correspondant dans le prompt final.

## Couleur de référence

| Nom | Hex | RGB | Rendu |
|-----|-----|-----|-------|
| Ambre Incandescente | `#FABA43` | 250, 186, 67 | Warm yellow-gold (dominante JAUNE, PAS orange). Comme un lingot d'or ou du blé mûr. |

> **IMPORTANT pour les prompts EN** : le mot "amber" pousse l'IA vers l'orange. Toujours utiliser **"warm gold"**, **"yellow-gold"**, **"marigold"** dans les prompts. Toujours exclure : `NOT orange, NOT burnt sienna, NOT terracotta`.
| Charbon (contraste) | `#1a1714` | 26, 23, 20 | Fond sombre profond, complément naturel |

## Utilisation dans les briefs

Dans le brief v3, ajouter le champ `Fond` dans la section Contraintes :

```
- Fond : `ambre-halo` (voir _config/fonds-ambre.md)
```

Le prompt engineer injecte le bloc `prompt` correspondant dans le prompt final, en remplacement de la description de fond habituelle ("dark matte background").

### Compatibilité modes

| Mode | Compatible | Note |
|------|:----------:|------|
| `full-ia` | OUI | Le fond est généré avec le produit |
| `compositing-ia` | OUI | Le fond fait partie de la scène IA |
| `compositing-irl` | PARTIEL | Possible si la photo produit est sur fond transparent/découpé |
| `irl-sublimation` | NON | La photo source a déjà son fond |
| `template` | OUI | Utilisable comme background CSS (couleur unie ou image) |
| `scene-ia` | NON | La scène photo réelle définit le fond |

### Combinaison avec brand shapes

Les fonds ambre se combinent naturellement avec les brand shapes du visual system :
- **Knockout band** : charbon sur fond ambre (comme `render-knockout-ambre.png`)
- **Pulse arcs** : charbon ou blanc sur fond ambre
- **Frame dome** : charbon sur fond ambre
- **Texture fill** : produit visible à travers les lettres sur fond ambre
