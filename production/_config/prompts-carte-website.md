# Prompts Carte Website — Catalogue produits uniforme

> Photos produits pour la page "La Carte" du site strictfood.vercel.app.
> **TOUS les produits partagent le MEME fond, le MEME eclairage, le MEME angle, le MEME format.**
> Seul le produit change. La coherence visuelle est ABSOLUE.

## Specifications communes (VERROUILLEES)

| Parametre | Valeur |
|-----------|--------|
| Format | 1:1 carre (1080x1080 ou 4K equivalent) |
| Fond | Dark matte charcoal (#1a1714), texture subtile, pas de sol visible — fond infini |
| Angle | STRAIGHT-ON at eye-level, produit parfaitement centre |
| Eclairage | Key light: hard side light from the UPPER-RIGHT at 45 degrees, warm golden temperature. Fill: gentle from the left. Rim: subtle warm edge light on the right side of the product separating it from the dark background |
| DOF | Shallow — product tack-sharp, edges of the dark background softening |
| Taille produit | Le produit occupe 55-60% de la hauteur du cadre pour les burgers, 40-45% pour les wraps/snacks. TOUS les burgers simples font la MEME taille. TOUS les MAX font la meme taille (plus grands que les simples). |
| Imperfections | 2-3 par photo : sesame seeds tombes, parmesan fragment, sauce droplet sur la surface |
| Sauce | Distribution HAUT → BAS : source visible entre le bun cap et les toppings, coule EN DESCENDANT le long du steak en 1-2 trails glossy. PAS de nappe/pool sur le bun base. PAS de flood. Le filet arrive en bas MINCE. Placement du cote de sortie DIFFERENT par produit (voir table). |

### Placement sauce par produit (JAMAIS le meme cote)

| Produit | Cote de sortie sauce | Description |
|---------|---------------------|-------------|
| Strict Boeuf | FRONT-LEFT | Sauce seeps from between bun cap and toppings on the LEFT, trails down the steak front-left in 2 thin glossy threads |
| Strict Poulet | BACK-RIGHT | Sauce seeps from between bun cap and toppings on the RIGHT, trails down the back-right of the steak |
| Strict Vege Falafel | CENTER-FRONT | Sauce seeps from between bun cap and falafel at the FRONT center, trails down the falafel face |
| Strict MAX Boeuf | RIGHT (between steaks) | Sauce seeps from between bun cap and toppings on RIGHT + also visible between the 2 steaks, trailing down |
| Strict MAX Poulet | LEFT (between portions) | Sauce seeps from between bun cap and toppings on LEFT + visible between the 2 chicken portions |
| Wrap Boeuf | Cross-section + thin drip from bottom | Sauce visible in cut face + thin drip hanging from wrap base |
| Wrap Poulet | Cross-section + trail on tortilla exterior | Sauce in cut face + thin trail on tortilla surface |
| Style | Documentary food photography, slightly imperfect, authentic. Subtle film grain. No text, no logos, no people, no hands. |
| Resolution | 4K |
| API | Gemini (Nano Banana Pro) |
