## Principes directeurs

1. **La photo EST le contenu.** Le texte est un bonus, pas une nécessité.
2. **Viscéral > Informatif.** Un gros plan qui donne faim vaut mieux qu'une fiche qui informe.
3. **Variété obligatoire.** Pas 2 stories consécutives avec le même concept.
4. **Évolutivité.** Chaque semaine a une "couleur créative" dominante (voir Micro-saisons).

#### Principes permanents

1. **Le témoin invisible** — La caméra est un passant. La personne ne sait pas qu'elle est photographiée. JAMAIS de regard caméra, JAMAIS de présentation du produit vers l'objectif.
2. **Le produit est le héros** — 50-60% du cadre, toujours net. L'humain est du contexte.
3. **Le fragment humain** — JAMAIS le visage entier. Maximum : mâchoire + bouche.
4. **L'imperfection candide** — Cadrage off-center, tilt, sauce sur le pouce, graine sur le menton.
5. **Specs caméra obligatoires** — Chaque prompt commence par "Shot on [modèle], [focale] [ouverture], ISO".

## Concepts Brand (pour stories full-ia brand : rappels, educatif, interactif, fiche produit)

> Ces stories portent un MESSAGE (horaires, macros, question, nom produit) mais le visuel IA est le hero.
> Le texte est INTEGRE dans la scene (overlay, natif IG) — jamais le sujet principal du visuel.
> L'agent `rappel-copywriter` choisit le concept + ecrit l'accroche. Les deux s'amplifient mutuellement.

### Principe : le visuel cree l'EMOTION, le texte cree l'ACTION

Le visuel ne repete PAS le texte. Si l'accroche dit "T'as survecu a la semaine", le visuel ne montre PAS quelqu'un qui survit — il montre la RECOMPENSE (le burger, le moment de plaisir). L'accroche accroche, le visuel donne envie, les horaires permettent d'agir.

### Categorie 1 — Objet Hero (un element isole, eleve au rang d'oeuvre)

### Anti-repetition Brand

- JAMAIS 2 rappels consecutifs dans la meme categorie (alterner objet hero / scene emotionnelle / abstrait / juxtaposition)
- JAMAIS le meme concept 2 fois en 3 semaines
- Le concept doit AMPLIFIER l'accroche du `rappel-copywriter`, pas la repeter
- La micro-saison de la semaine influence le choix (Macro & Texture → `brand-bun-noir`, `brand-sesame-pluie` ; Action & Energie → `brand-countdown`, `brand-cuisine-vapeur` ; etc.)

---

## Micro-saisons visuelles (rotation hebdomadaire)

> Chaque semaine a une "couleur créative" dominante qui influence les choix de concepts.
> Ne pas suivre rigidement — c'est une tendance, pas une contrainte absolue.

| Semaine (mod 4) | Couleur créative | Concepts dominants |
|-----------------|-----------------|-------------------|
| Semaine A | **Macro & Texture** | macro-*, sensation-brillance, sensation-goutte, texture close-ups |
| Semaine B | **Action & Énergie** | action-*, moment-rush, sensation-crunch, mixed-motion-blur |
| Semaine C | **Atmosphère & Lumière** | atmo-*, persp-*, mixed-selective-color, mixed-grain-cinema |
| Semaine D | **Moments & Storytelling** | moment-*, serie-*, sensation-overflow, ambiance IRL |

> Rotation : S3=A, S4=B, S5=C, S6=D, S7=A, etc.

## Comment utiliser ce fichier

1. **Au planning** : choisir un concept pour chaque story (colonne "Concept visuel") — food porn, lifestyle, OU brand
2. **Au brief** : le concept choisi guide l'art direction et le prompt
3. **À la production** : le type (food / lifestyle / brand) détermine le sous-pipeline, le concept détermine le RENDU
4. **Brand/Rappel** : l'agent `rappel-copywriter` choisit le concept brand et ecrit l'accroche. Le visuel amplifie l'accroche.
5. **Anti-répétition** : vérifier que 2 stories consécutives n'utilisent pas le même concept. Pour les brand : pas 2 dans la meme categorie d'affilee.
6. **Micro-saison** : consulter la couleur de la semaine pour orienter les choix (y compris brand)
