# Bibliothèque de Concepts Visuels — Stories & Posts

> Source d'inspiration pour le planning. Chaque story non-template DOIT avoir un concept visuel assigné.
> Consulté à l'étape 1 du planning (après l'historique) pour varier les approches.

---

## Principes directeurs

1. **La photo EST le contenu.** Le texte est un bonus, pas une nécessité.
2. **Viscéral > Informatif.** Un gros plan qui donne faim vaut mieux qu'une fiche qui informe.
3. **Variété obligatoire.** Pas 2 stories consécutives avec le même concept.
4. **Évolutivité.** Chaque semaine a une "couleur créative" dominante (voir Micro-saisons).

### Humain + Produit — Système combinatoire

> Ces concepts montrent une PERSONNE interagissant avec le produit. Réalisables en `full-ia` (visages IA), `irl` ou `irl-sublimation` (photos réelles). En full-ia, la description du produit est ULTRA-FIDÈLE à la recette.
>
> **Principe** : chaque visuel est COMPOSÉ en piochant une brique dans chaque catégorie. Aucun template figé — la variété vient de la combinatoire.

#### Brique 1 — Cadrage (fragment humain visible)

| Cadrage | Ce qu'on voit | Quand |
|---------|--------------|-------|
| `cadrage-bouche` | Bouche, menton, mâchoire, bout du nez | Croque, anticipation, réaction gustative |
| `cadrage-profil` | Profil latéral : mâchoire, oreille, joue | Burger tenu de côté, regard latéral |
| `cadrage-mains` | Mains + produit uniquement, aucun visage | Geste pur : tenir, déchirer, tremper, sortir du sac |
| `cadrage-dos` | Dos de la tête + épaule, burger visible | Vue par-dessus l'épaule, voyeurisme |
| `cadrage-silhouette` | Personne en silhouette floue, burger NET | Contre-jour, le produit "vole la vedette" |
| `cadrage-plongee` | Menton + mains vus d'au-dessus | Personne assise qui mange |

#### Brique 4 — Caméra (style de capture)

| Caméra | Setup | Feeling |
|--------|-------|---------|
| `cam-telephoto` | 200mm f/2.8, ISO 400 | Candid volé, paparazzi |
| `cam-portrait` | 85mm f/1.8, ISO 200 | Intime, bokeh crémeux |
| `cam-street` | 35mm f/2.0, ISO 400 | Reportage, contexte visible |
| `cam-flash` | 50mm f/4.0, flash frontal | Éditorial BK, hyper-détaillé |
| `cam-contrejour` | 85mm f/2.0, backlit | Silhouette dramatique |
| `cam-mobile` | 26mm f/1.8 (smartphone) | Ultra-candid, authentique |

#### Principes permanents

1. **Le témoin invisible** — La caméra est un passant. La personne ne sait pas qu'elle est photographiée. JAMAIS de regard caméra, JAMAIS de présentation du produit vers l'objectif.
2. **Le produit est le héros** — 50-60% du cadre, toujours net. L'humain est du contexte.
3. **Le fragment humain** — JAMAIS le visage entier. Maximum : mâchoire + bouche.
4. **L'imperfection candide** — Cadrage off-center, tilt, sauce sur le pouce, graine sur le menton.
5. **Specs caméra obligatoires** — Chaque prompt commence par "Shot on [modèle], [focale] [ouverture], ISO".

## Micro-saisons visuelles (rotation hebdomadaire)

> Chaque semaine a une "couleur créative" dominante qui influence les choix de concepts.
> Ne pas suivre rigidement — c'est une tendance, pas une contrainte absolue.

| Semaine (mod 4) | Couleur créative | Concepts dominants |
|-----------------|-----------------|-------------------|
| Semaine A | **Macro & Texture** | macro-*, sensation-brillance, sensation-goutte, texture close-ups |
| Semaine B | **Action & Énergie** | action-*, moment-rush, sensation-crunch, mixed-motion-blur |
| Semaine C | **Atmosphère & Lumière** | atmo-*, persp-*, mixed-selective-color, mixed-grain-cinema |
| Semaine D | **Moments & Storytelling** | moment-*, serie-*, sensation-overflow, ambiance IRL |

> Rotation : S3=A, S4=B, S5=C, S6=D, S7=A, etc.

## Comment utiliser ce fichier

1. **Au planning** : choisir un concept pour chaque story non-template (colonne "Concept visuel")
2. **Au brief** : le concept choisi guide l'art direction, le choix de photo, et le prompt
3. **À la production** : le mode (irl-sublimation, full-ia, etc.) détermine le pipeline, le concept détermine le RENDU
4. **Anti-répétition** : vérifier que 2 stories consécutives n'utilisent pas le même concept
5. **Micro-saison** : consulter la couleur de la semaine pour orienter les choix
