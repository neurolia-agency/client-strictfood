Les briefs — entree du systeme

Le brief est le document d'entree de chaque contenu. Il contient ce que l'operateur veut, et le pipeline fait le reste. Deux types de briefs, deux templates.

📄

Brief Post

Un brief par post. Contient le pilier, le mode (deja decide au planning), le produit, les sources visuelles selon le mode, et la Direction Caption.

Template
_templates/brief-v3.md
Emplacement
DD-MM-YYYY/brief/brief.md
📄

Brief Story

Un brief par jour. Contient toutes les stories du jour avec pour chacune : le type, le mode (decide au planning), le contenu specifique au type.

Template
_templates/brief-story.md
Emplacement
S[X]/[jour]/brief/brief-story.md

Comment un brief est genere

1

Le planning decide

Le pilier, le mode, le produit/sujet et le type (pour les stories) sont deja dans le planning valide. Le brief ne fait que les reprendre.

2

L'operateur complete

L'objectif (1-3 phrases), les sources visuelles (photos pour les modes IRL/compositing), la Direction Caption (angle, ton, CTA, mentions). Pas de caption complete — elle sera generee apres l'image.

3

Le pipeline lit le brief

L'orchestrateur (/instagram-producer ou /story-producer) lit le brief, extrait le mode, et route vers le bon sous-pipeline.

Regle cle : le brief ne contient PAS la caption (seulement une Direction Caption). La caption est generee APRES l'image par le skill /caption-writer qui analyse visuellement le resultat.

Les Skills

Les skills sont des competences invocables par commande. Ils orchestrent, generent, ou servent de reference.

🎯

instagram-producer

Orchestrateur principal des posts. Detecte le mode dans le brief et route vers le bon sous-pipeline. Enchaine automatiquement toutes les etapes.

INVOCATION
/instagram-producer DD-MM-YYYY
PRODUIT — Image + caption dans final/ + production/
📱

story-producer

Orchestrateur des stories. Enchaine copywriting → data mapping → validation → template fill → render pour chaque story du jour.

INVOCATION
/story-producer S[X] [jour]
PRODUIT — PNG 1080x1920 dans story-NN/final/
🎨

social-media-art-director

Transforme le brief en direction creative visuelle detaillee : angles, eclairage, composition, mood. Ne voit JAMAIS les photos — travaille sur concept pur.

APPELE PAR — instagram-producer (modes full-ia, compositing-ia)
PRODUIT — production/art-direction.md
✍️

image-prompt-engineer

Transforme la direction creative en prompt de generation image optimise pour Gemini ou GPT Images. Respecte la fidelite ingredients.

APPELE PAR — instagram-producer (modes full-ia, compositing-ia)
PRODUIT — production/prompt.md
🖼️

nano-banana-pro

Genere et edite des images via l'API Gemini 3 Pro Image. Text-to-image et image-to-image. Resolutions 1K, 2K ou 4K.

INVOCATION
/nano-banana-pro --resolution 4K
PRODUIT — PNG dans final/
📝

caption-writer

Genere la caption Instagram APRES l'image. Analyse visuellement le PNG produit, croise avec la Direction Caption du brief et les 15 dernieres captions.

APPELE PAR — instagram-producer (tous les modes, etape finale)
PRODUIT — production/caption.md

Reference

Les Agents

Les agents sont des sous-processus specialises lances automatiquement par les orchestrateurs. Chaque agent a un role deterministe et un modele dedie.

🗺️

input-mapper

Haiku

Resout les liens produit → photo + recette. Lit la direction creative, consulte le catalogue photos et les fiches recettes. Role deterministe : pas de creativite, juste du mapping.

LIT — art-direction.md + photo-references.md + _recettes/
PRODUIT — production/input.md
✏️

story-copywriter

Sonnet

Reecrit les textes des briefs stories pour plus de punch, moins de redondance. Respecte les limites de caracteres par zone de template. Registre streetfood premium.

LIT — brief-story.md + SPECS.md (limites caracteres)
PRODUIT — Textes reecris (integres au flux)
📊

story-data-mapper

Haiku

Resout les donnees produit (macros, prix, ingredients), photos, brand props et presets pour les stories. Assigne les presets photo et forces gradient. Role deterministe.

LIT — brief + _recettes/ + photo-references.md + brand-props.md + SPECS.md
PRODUIT — story-NN/production/data.md
🎬

strict-irl-prompter

Sonnet

Specialiste des prompts lifestyle "STRICT IRL". Transforme un concept en prompt optimise pour Gemini avec focus sur fidelite produit, realisme humain et coherence photographique.

PRODUIT — Prompt de generation lifestyle (EN, Gemini 4K)
🔀

strict-irl-compositor

Sonnet

Specialiste du compositing photo reelle + scene. Integre un vrai produit dans une scene lifestyle via multi-image Gemini. Matching eclairage, ombres, perspective.

PRODUIT — Prompt compositing multi-image (EN, Gemini 4K)
🔄

product-variant-generator

Sonnet

Genere des variantes visuelles d'un produit (angles, eclairages, cadrages) via GPT Images. Le produit reste fidele — seule la presentation change. Utilise en pre-batch semaine.

PRODUIT — Variantes PNG + entree dans product-variants.md
