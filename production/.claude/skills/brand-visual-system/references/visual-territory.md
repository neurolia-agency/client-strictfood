# Visual Territory — Analyse sectorielle

Comment analyser le territoire visuel d'un secteur pour identifier les opportunites
de differenciation et eviter les codes satures.

---

## Framework d'analyse

### 1. Scanner les codes dominants

Lister les 5-10 codes visuels les plus utilises dans le secteur de la marque.

**Exemple food/restauration rapide :**

| Code | Frequence | Exemples |
|------|-----------|----------|
| Fond rouge/jaune vif | Tres haute | McDonald's, Burger King, Five Guys |
| Typo sans-serif grasse blanche | Tres haute | Presque tout le monde |
| Sparkles/etoiles decoratives | Haute | Enjoy Tacos, feeds generiques |
| Drips/coulures | Haute | Feeds desserts, glaces, sauces |
| Photo-only sans overlay | Haute | Comptes de chefs |
| Flat lay ingredients | Moyenne | Comptes healthy |
| Stickers/autocollants | Moyenne | Feeds "fun" et "street" |
| Geometric frames | Basse | Feeds premium/editorial |
| Texture/grain cinematique | Basse | Feeds haut de gamme rares |
| Typographie comme element graphique | Basse | Feeds mode/luxe adaptes food |

### 2. Classer par saturation

| Zone | Signification | Action |
|------|--------------|--------|
| **Sature** (>60% des concurrents l'utilisent) | Invisible. L'element ne differencie plus. | EVITER sauf si execution radicalement differente |
| **Frequent** (30-60%) | Reconnaissable mais banal. | UTILISER seulement avec une torsion unique |
| **Rare** (<30%) | Opportunite. Peu de concurrents y vont. | EXPLORER — potentiel de differenciation |
| **Inexistant** (0%) | Soit c'est une mauvaise idee, soit c'est un ocean bleu. | ANALYSER pourquoi personne ne le fait |

### 3. Definir le territoire exclusif

Le territoire exclusif = l'intersection de :
- Ce que la marque EST (positionnement, produit, process)
- Ce que les concurrents NE FONT PAS (zone rare ou inexistante)
- Ce qui est visuellement impactant a l'echelle d'un feed Instagram

**Template de synthese :**

```
MARQUE : [nom]
SECTEUR : [secteur]
POSITIONNEMENT : [premium / street / craft / etc.]

CODES SATURES (a eviter) :
- [code 1] — pourquoi c'est sature
- [code 2]

OPPORTUNITES (a explorer) :
- [code rare 1] — pourquoi ca matche avec la marque
- [code rare 2]

TERRITOIRE EXCLUSIF :
"[Phrase qui resume l'espace visuel unique de la marque]"
Exemple : "Le food porn cinematique sur fond ambre — personne dans le fast healthy
ne fait du noir + dore avec du grain cinema"
```

## Benchmarks par positionnement

### Premium / Dark / Haut de gamme

| Ce qui fonctionne | Ce qui echoue |
|-------------------|---------------|
| Negative space genereuse | Surcharge d'elements decoratifs |
| Typographie comme graphisme (grande, bold, architecturale) | Petits sparkles decoratifs (= clip-art) |
| Color grading cinematique (grain, contraste pousse, palette restreinte) | Filtres Instagram basiques |
| Textures materielles (papier, metal, pierre) | Aplats de couleur sans profondeur |
| 1-2 elements signature repetes avec variations | 5+ elements differents qui se battent |
| Asymetrie maitrisee | Centrage systematique (= ennuyeux) |

### Street / Urban / Expressif

| Ce qui fonctionne | Ce qui echoue |
|-------------------|---------------|
| Stickers/collage avec energy brute | Stickers stock generiques |
| Typo condensed ultra-bold qui deborde du cadre | Typo sagement contenue dans le cadre |
| Mouvements (rotations, decalages, superpositions) | Composition statique centree |
| Couleurs saturees en blocs | Degradees subtiles (= trop sage) |
| Imperfections voulues (bords decoupes, textures rugueuses) | Proprete excessive |

### Craft / Artisanal / Authentique

| Ce qui fonctionne | Ce qui echoue |
|-------------------|---------------|
| Textures papier kraft, bois, tissu | Aplats numeriques purs |
| Typographie script ou serif avec caractere | Sans-serif generique |
| Illustrations faites main (ou qui semblent) | Illustrations vectorielles trop propres |
| Palette terreuse/naturelle | Couleurs fluo ou trop numeriques |
| Photos avec imperfections volontaires | Photos trop leechees/retouchees |

## Red flags sectoriels

Elements qui signalent immediatement "generique" dans certains secteurs :

| Secteur | Red flag | Pourquoi |
|---------|----------|----------|
| Food | Sparkles 4 branches jaunes | Sur-utilise par Enjoy Tacos et 200 copies |
| Food | Drip/coulure depuis le haut | Sur-utilise depuis 2020 |
| Food | Rond avec "NOUVEAU" | Utilise par absolument tout le monde |
| Beaute | Blob organique rose | Code generique des marques clean beauty |
| Tech | Gradient bleu-violet | Sature depuis 2018 |
| Mode | Cadre fin minimaliste | Devenu le "normal", ne differencie plus |

## Recherche de references

Pour scanner un secteur, examiner :
1. Les 10-15 concurrents directs (meme secteur, meme positionnement)
2. Les 5-10 marques aspirationnelles (le niveau au-dessus en DA)
3. Les 3-5 marques hors-secteur avec le meme positionnement (ex: marque mode premium si on fait du food premium — ils partagent les memes codes de luxe)

Pour chaque : noter les brand elements recurrents, les couleurs dominantes, le ratio photo/graphisme.
