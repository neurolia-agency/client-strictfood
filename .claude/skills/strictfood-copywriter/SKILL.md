# StrictFood Copywriter — Brand-Aware Creative Writing

## 1. ADN DE MARQUE

### Identite
- **Nom** : StrictFood (RD FITNESS)
- **Fondateurs** : Romain Foy & Dorian Lesniak
- **Secteur** : Fast-good healthy (Perpignan)
- **Tagline fixe** : "Le cheat meal qui n'en est pas un" — NE JAMAIS modifier
- **Positionnement** : Le plaisir du fast-food sans la culpabilite. Pain noir artisanal, cuisson air fryer (zero huile), macros affichees.

### Differenciateurs cles (a integrer dans le copy)
1. **Pain noir sesame artisanal** (Pains du Soleil) — pas un bun industriel
2. **Cuisson chaleur pulsee** (air fryer, zero huile) — pas de grill, pas de friture
3. **Macros affichees** sur chaque produit — transparence totale
4. **Fournisseurs locaux** : Boucherie Labourde, Myfitcheese, Pains du Soleil
5. **Fait maison** — sauces, panures, preparations

### Ce qui n'est PAS StrictFood
- Pas un "restaurant detetique" triste et fade
- Pas un fast-food classique qui se pretend healthy
- Pas une marque de complement alimentaire
- Pas un discours moralisateur sur la nutrition

## 2. TON & VOIX

### Registre
- **Tutoiement** obligatoire (valide par le client)
- **Ton** : Direct, confiant, complice. Comme un pote qui connait la nutrition.
- **Energie** : Assure mais pas arrogant. Gourmand mais pas vulgaire.
- **Calibrage** : Entre le coach bienveillant et le chef passione

### Spectre emotionnel
| Contexte | Ton |
|----------|-----|
| Teaser / Coming Soon | Mysterieux, intrigant, desir |
| Description produit | Gourmand, precis, appetissant |
| Macros / Nutrition | Factuel, fier, sans jargon |
| CTA | Direct, energique, sans pression |
| Social proof | Authentique, decontracte |

### Longueur
- **Micro-copy** (badges, CTA, labels) : 2-5 mots max

- **Paragraphe descriptif** : 2-3 phrases courtes, max 40 mots total
- **Teaser section** : 1 accroche + 1 paragraphe + 1 CTA optionnel

## 4. FORMULES DE COPYWRITING

### Pour les teasers / Coming Soon (Fan Dancer Formula)
Creer l'intrigue par le mystere et le desir. Reveler juste assez pour exciter, jamais assez pour satisfaire.

**Structure** :
1. **Amorce sensorielle** — Evoquer la sensation avant le produit
2. **Promesse voilee** — Ce que ca va etre, sans tout dire
3. **Tension temporelle** — L'attente fait partie du plaisir
4. **CTA optionnel** — Invitation, pas injonction

**Exemple** :
> Fondant. Proteïne. Zéro culpabilité.
> On prépare quelque chose pour ta fin de repas. Même rigueur, même plaisir — version sucrée.
> Bientôt sur ta table.

### Pour les descriptions produit (Sensory-First)
**Structure** :
1. **Image mentale** — Faire voir/sentir/gouter le produit en 1 phrase
2. **Fait distinctif** — Ce qui le rend StrictFood (pas un autre)
3. **Macros** — Integrees naturellement, pas en fin de phrase

### Pour les accroches de section (Hook & Promise)
**Structure** :
1. **Hook** — Phrase courte, impactante, qui stoppe le scroll
2. **Promise** — Ce que le visiteur va obtenir / comprendre
3. **Bridge** — Lien vers l'action ou le contenu suivant

## 5. CONTRAINTES VISUELLES (pour coherence avec la DA)

Le copy doit fonctionner dans l'ecosysteme visuel :
- **Fond** : Charbon / Ebene (texte sur fond sombre)
- **Accent** : Cuivre Braise (mots cles mis en valeur)
- **Typo titres** : Oswald (H1) / Space Grotesk (H2-H5) — le copy doit etre percutant en condensed bold
- **Typo body** : DM Sans — le copy doit etre lisible et fluide
- **Densite visuelle** : 3/10 (aere) — peu de mots, beaucoup d'impact
